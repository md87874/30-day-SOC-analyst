<h1>30 Day SOC analyst challenge</h1>


<h2>Description</h2>
I came across an engaging project on MyDFIR's YouTube channel focused on establishing a personal SOC analyst work environment, allowing for hands-on practical experience. Here are some of the key tasks I accomplished during the project:

- Spun up my own Elastic search and Kibana instance 

- Spun up two servers (a Linux SSH server & Windows RDP server 

- Installed Elastic agent on both servers to push logs into Elatsticsearch 

- Created alerts and dashboards for detecting brute force activity and identifying Mythic C2 activity 

- Spun up my own ticketing system using OsTicket 


<h2>Environments Used </h2>

- <b>Ubuntu 22.04</b>
- <b>Windows Server 2022</b>
- <b>Windows 10</b>
